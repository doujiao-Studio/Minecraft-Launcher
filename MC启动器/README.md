# MCL·神启动器 (Minecraft Launcher)

> 一个整合「**启动器 + 版本管理 + 下载中心 + 服务器管理 + 内网穿透**」的一站式我的世界工具。
> 专门解决学生党最头疼的问题：**没有公网 IP，怎么让朋友进你的服务器？**

纯 Python 标准库 + Tkinter 实现，**零第三方依赖**；提供**免安装绿色单文件 exe**，目标电脑无需安装 Python 即可运行。

- 🇨🇳 **中文友好**：支持中文关键词自动翻译搜索；模组名本地词典即时翻译；模组详情页可一键翻译简介

- 🌐 **内网穿透**（核心亮点）：局域网直连 / 自建中继隧道 / 免费 SSH 隧道，**没有公网 IP 也能开服**

## 🚀 快速开始

### 方式 A：免安装绿色版（推荐，浏览者直接可用）

从右侧 **Releases** 下载 `MCL神启动器-免安装版.zip`，解压后双击 `MCL-Launcher.exe` 即可。

首次使用请到「设置」页点「**自动检测**」定位 Java（或手动浏览选择 `java.exe`）。

### 方式 B：源码运行

需要 Python 3.10+（Windows），克隆仓库后：

```bat
python main.py
```

或直接双击 `start.bat`。

## 📖 使用说明（六个标签页）

### 1️⃣ 启动器
- 从镜像拉取全部版本清单（release + snapshot，900+ 版本）
- 一键下载该版本的客户端、依赖库、资源文件（实时进度）
- 自动按版本选择匹配的 Java，装配启动命令并拉起游戏
- 内置游戏控制台：实时看日志、发命令；支持离线 / 正版两种账号模式

### 2️⃣ 版本管理
- 自动列出已下载的版本（类型 / 所需 Java / 客户端大小 / 模组数）
- 一键打开对应版本的 **模组文件夹 / 资源包文件夹 / 存档文件夹 / 数据包文件夹 / 游戏目录**
- **直接添加模组**：选 `.jar` 复制进当前版本的 `mods` 文件夹
- **直接添加资源包**：选 `.zip` 复制进 `resourcepacks` 文件夹
- 可删除不再需要的版本（删除前二次确认）

### 3️⃣ 下载中心（五个子页）
| 子页 | 内容 |
|---|---|
| 游戏本体 | 浏览并下载 Minecraft 各版本客户端，下载完去「启动器」页启动 |
| 模组 | Modrinth 搜索并安装模组（按版本 + Forge/Fabric/NeoForge/Quilt 过滤） |
| 资源包 | Modrinth 搜索并安装资源包 |
| 数据包 | Modrinth 搜索并安装数据包 |
| 更多 | 光影 / 整合包 / 插件 |

- **按版本自动归档**：模组 → `.minecraft/<版本>/mods`，资源包 → `.minecraft/<版本>/resourcepacks`，数据包 → `.minecraft/<版本>/datapacks`；也可点「**下载到自定义位置…**」选任意目录
- **中文搜索**：搜索框输入中文自动翻译成英文再搜（默认开启）
- **模组详情页**：单击搜索结果即打开——完整简介（可翻译成中文 / 恢复原文）、跳转 **MC百科** 与 **Modrinth** 官方页、「可用版本」按 Minecraft 版本分组显示该模组所有版本（带分隔标题）、「更新记录」列出版本历史，加载失败可点「刷新版本」重试
- 说明：Modrinth 在国内网络可能较慢，搜索与下载都在后台线程执行，不卡界面

### 4️⃣ 服务器
- 一键创建服务器：**原版 (vanilla)** 和 **Paper** 两种服务端，自动下载
- 启动 / 停止 / 重启，实时控制台可发 `op`、`whitelist` 等命令
- 可视化编辑 `server.properties`（端口、MOTD、游戏模式、难度、正版验证等）
- 白名单 / OP 名单按行编辑保存
- 一键把 `world` 打包备份，随时查看备份列表

### 5️⃣ 内网穿透（没有公网 IP 也能开服）
| 方式 | 适用场景 | 需要公网 IP 吗 |
|---|---|---|
| 局域网直连 | 同一 WiFi/路由器下的同学 | 否 |
| **自建中继隧道** | 任何情况（推荐） | **否**（只需一台公网主机） |
| 免费 SSH 隧道 | 图省事 | 否 |

**自建中继隧道原理**：你的电脑与一台公网「中继服务器」保持连接；玩家连接中继端口时，中继让你的电脑主动发出站连接，两端对接。**你的电脑全程只发出站连接，所以没有公网 IP 也能开服。**

步骤：
1. 找一台有公网 IP 的机器（免费云主机、同学的公网主机），也装 Python；
2. 在那台机器上运行：`python -m mcl.tunnel.relay_server --token 你的密钥 --public-host 那台机器的IP`
3. 回本机「内网穿透」页填中继地址、控制端口(6000)、相同密钥，点「启动隧道」；
4. 把界面给出的 **公网地址:映射端口** 发给朋友，他们输入即可加入。

### 6️⃣ 设置
- Java 自动检测 / 手动浏览；JVM 参数；内存分配
- 下载镜像切换（Mojang 官方 / BMCLAPI）
- 认证模式（离线 / 正版）、启动参数

## 🛠️ 常见问题

- **窗口没有系统标题栏，怎么拖动/缩放？** 按住顶部品牌区拖动，双击顶部最大化/还原，右上角三个按钮控制最小化/最大化/关闭。
- **启动报「未找到 Java」/「需要 Java X，本机最高只有 Java Y」**：启动器会自动按版本选匹配的 Java；请安装对应 Java（新版 MC 需要 17/21/25），或在下载中心选更低的 MC 版本。
- **版本下载很慢**：设置页把「下载镜像」切到 `bmclapi`（国内镜像）。
- **下载中心搜索很慢/偶尔失败**：Modrinth 在国内网络时快时慢，界面自动转后台，多试几次即可；建议填具体名称 + 选对游戏版本/加载器。
- **下载的模组进游戏没生效**：模组必须配合对应加载器（Forge/Fabric/NeoForge）才能加载，请先用对应加载器建好客户端实例再装模组。
- **中继连不上**：确认公网主机的控制端口(6000)和回连端口已在安全组/防火墙放行。
